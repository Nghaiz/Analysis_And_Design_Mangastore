## Đề xuất sửa file dùng chung (orchestrator áp dụng)

### 1. `compose.yaml`, service `db` (bắt buộc trên Windows)

Thay dòng mount conf.d và thêm `entrypoint`. Đã chạy thử đúng lệnh này (phương án B ở trên):

```yaml
  db:
    image: mysql:8.4.13
    # Docker Desktop trên Windows mount file với quyền 0777, MySQL bỏ qua file cấu hình world-writable;
    # chép vào /etc/mysql/conf.d với mode 0644 trước khi chạy entrypoint gốc.
    entrypoint: ["sh", "-c", "install -m 0644 /docker-conf.d/*.cnf /etc/mysql/conf.d/ && exec docker-entrypoint.sh mysqld"]
    ...
    volumes:
      - db_data:/var/lib/mysql
      - ./docker/mysql/conf.d:/docker-conf.d:ro
```

Nếu muốn ít thay đổi hơn, dùng phương án A: giữ mount cũ và thêm `command: ["--character-set-server=utf8mb4", "--collation-server=utf8mb4_0900_ai_ci", "--default-time-zone=+07:00"]`. Khi đó ba giá trị bị viết hai nơi, và CLI `docker compose exec db mysql` vẫn dùng `latin1`: dán tiếng Việt vào sẽ hỏng chữ, trừ khi thêm `--default-character-set=utf8mb4`. Tôi đề nghị dùng B. `plan-contract.test.mjs` chỉ kiểm mount kiểu volume của `db` (`db_data`), nên cả hai phương án đều không làm test đỏ.

Accept phase 1 nên thêm một bước: `docker compose exec db mysql ... -e "SELECT @@time_zone"` phải ra `+07:00`. Hiện chưa bước nào phát hiện được lỗi này, vì charset mặc định của 8.4 vốn đã đúng.

### 2. `compose.yaml`, service `redis` (nên sửa: hạ quyền)

```yaml
    command: ["sh", "-c", "exec docker-entrypoint.sh redis-server /usr/local/etc/redis/redis.conf --requirepass \"$$REDIS_PASSWORD\""]
```

Đã chạy thử lệnh này: Redis chạy bằng uid 999, PONG, NOAUTH khi không gửi mật khẩu. Lưu ý với volume `redis_data` đã có từ trước: entrypoint tự `chown` các file không thuộc `redis` trong `/data` ở lần khởi động đầu, nên không cần xoá volume.
